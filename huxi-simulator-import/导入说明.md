# 虎溪校区批量模拟路灯导入说明

本数据包包含 24 台模拟路灯，编号为 `SIM-HUXI-001` 至 `SIM-HUXI-024`。
真实硬件固定保留编号 `HW-001`，数据包中没有模拟该设备。

## 导入

1. 完全关闭“鸿蒙传感器模拟器”。
2. 将桌面现有的 `C:\Users\Lawrence\Desktop\sensors.dat` 重命名为 `sensors-backup.dat`。
3. 把本目录中的 `sensors.dat` 复制到桌面：
   `C:\Users\Lawrence\Desktop\sensors.dat`
4. 重新打开 `javafx-demo-1.0-SNAPSHOT.jar`。
5. MQTT 设置为 `127.0.0.1`、端口 `1883`，账号和密码留空，然后连接。
6. 点击各设备卡片上的“启动”，设备会每 5–8 秒持续上报数据。

## 遥测字段

每台设备上报：`deviceId`、`lux`、`temperature`、`humidity`、`voltage`、
`current`、`power`、`energy`、`lampStatus`、`ts`，同时携带设备名称、地点和演示坐标。

数据主题格式：`device/SIM-HUXI-xxx/data`。

控制主题格式：`device/SIM-HUXI-xxx/cmd`。

软件会让 Payload 中的数值字段在基准值上下约 10% 自动浮动。

## 真实硬件

真实设备使用 `HW-001`：

- 上报主题：`device/HW-001/data`
- 控制主题：`device/HW-001/cmd`
- 不要在模拟器中新增或启动同名设备

`huxi-sensors.json` 是便于核对的可读清单；模拟器实际导入的是 `sensors.dat`。
