# 智慧路灯系统 D1-D15 每日任务清单

本文档按校内前 15 天软件开发阶段编写，范围限定为智慧路灯系统第一阶段开发版本：模拟数据接入、后端业务、前端可视化、IoT/MQTT 预留、AI 维护问答、系统测试与部署。不包含真实硬件开发、真实传感器接线、GPIO/I2C/SPI/UART 驱动和基地阶段真实设备联调。

## 分工总览

| 成员 | 角色 | 负责范围 |
|---|---|---|
| 1号 | 项目经理与需求文档负责人 | 需求、计划、会议记录、验收标准、答辩材料 |
| 2号 | 前端与数据可视化负责人 | `frontend/` 页面、组件、交互、可视化 |
| 3号 | 后端与数据库负责人 | `backend/routes/`、`backend/services/`、`backend/store/`、`backend/models/`、`data/` |
| 4号 | IoT 模拟设备与 MQTT 通信负责人 | `backend/simulator/`、`backend/iot/` |
| 5号 | AI 智能体与 RAG 负责人 | `backend/agent/`、`backend/rag/` |
| 6号 | 系统测试、集成与部署负责人 | 测试用例、联调、部署、验收记录 |

## 每日公共检查项

每天结束前，所有成员需要完成以下检查：

1. 自己负责目录中的代码或文档已保存。
2. 影响接口字段、目录结构、启动方式的改动已通知 1号和 6号。
3. 2号和 3号确认前后端接口是否一致。
4. 4号和 3号确认模拟数据是否能进入后端业务逻辑。
5. 5号和 2号确认问答接口是否能在页面展示。
6. 6号执行 `npm run dev` 并检查首页和 `/api/summary`。
