# 测试用例

负责人：6号。

## 启动测试

| 编号 | 场景 | 步骤 | 预期 |
|---|---|---|---|
| TC-01 | 服务启动 | 执行 `npm run dev` | 控制台输出本地访问地址 |
| TC-02 | 首页访问 | 打开 `http://localhost:3000` | 页面正常显示 |
| TC-03 | 摘要接口 | 请求 `/api/summary` | 返回设备、指标、告警数据 |

## 核心业务测试

| 编号 | 场景 | 步骤 | 预期 |
|---|---|---|---|
| TC-04 | 低光自动开灯 | 切换“低光”场景 | 路灯状态变为开灯 |
| TC-05 | 高光自动关灯 | 切换“高光”场景 | 路灯状态变为关灯 |
| TC-06 | 手动控制 | 点击开灯/关灯按钮 | 设备状态随操作变化 |
| TC-07 | 离线告警 | 切换“离线”场景并等待心跳超时 | 出现 OFFLINE 告警 |
| TC-08 | 维护问答 | 输入“设备离线怎么排查” | 返回维护建议和来源 |
